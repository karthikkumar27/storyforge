Architecture Approaches

Choose the structure for your Cinematic AI Agent pipeline

A

Monolithic Script

Single Python file handles everything — GSheet read, Claude script gen, Kling API, ffmpeg, YouTube upload. Runs as one Cloud Function.

Pros

  • Simple to deploy
  • Easy to debug

Cons

  • Hard to test each stage
  • One failure breaks everything
  • Can't swap tools easily
B

Modular Pipeline ⭐ Recommended

Claude orchestrates 5 independent modules. Each module has one job and can be tested, swapped, or extended without touching others.

GSheet Reader → Script Generator → Video Producer → Audio Mixer → YouTube Uploader

Pros

  • Each stage is independently testable
  • Easy to swap Kling for another tool
  • Claude orchestrates intelligently
  • Clear error isolation

Cons

  • More files to manage
C

Event-Driven Microservices

Each stage is a separate Cloud Function. Cloud Tasks / Pub/Sub connects them. Maximum scalability — process 10 videos in parallel.

Pros

  • Highly scalable
  • Retry individual stages
  • Parallel video processing

Cons

  • Complex GCP setup
  • Harder to debug
  • Overkill for daily single video
