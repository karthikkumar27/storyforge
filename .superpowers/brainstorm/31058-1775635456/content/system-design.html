System Design — Cinematic AI Agent

Full pipeline: Google Sheets → Script → Video → Audio → YouTube

Trigger
☁️ GCP Cloud Scheduler — fires daily at 10:00 PM UTC+8 (14:00 UTC) → invokes Cloud Function
Pipeline Flow
1
GSheet Reader — scans for rows with status=pending, picks first unprocessed row, reads story_brief + metadata
↓
2
Script Generator (Claude) — generates cinematic narrative script from the brief in sci-fi / outer space / subtle horror genre blend. Outputs: script_text + shots[] (6–9 Kling prompts, ~10 sec each)
↓
3
Video Producer — sends each shot prompt to Kling AI API (Access Key + Secret JWT auth), downloads MP4 clips, stitches with ffmpeg into one 60–90 sec video
↓
4
Audio Mixer — Claude picks narrator voice (sci-fi→Adam, horror→Arnold, blend→Antoni), ElevenLabs generates voiceover, adds royalty-free atmospheric music, ffmpeg mixes both onto video
↓
5
YouTube Uploader — Claude generates title, description, tags. Uploads via YouTube Data API v3 (OAuth2). Updates GSheet row: status=done, writes YouTube URL
GSheet Schema
Column Type Description
titlestringOptional video title hint
story_briefstring1–3 sentence idea. Claude generates full script from this.
script_textstringAuto-filled by Claude after generation
genreenumsci-fi / horror / space / blend
duration_secintTarget duration (default: 75)
statusenumpending → generating → uploading → done / error
youtube_urlstringAuto-filled after upload
error_msgstringFilled if status=error
Error Handling
Each module catches its own exceptions → writes status=error + error_msg to GSheet row → pipeline stops for that row. Next day's run skips error rows unless manually reset to pending.
